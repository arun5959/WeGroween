## Fonts

Fraunces, DM Sans, Newsreader and Manrope are self-hosted variable WOFF2 files. Their corresponding SIL Open Font License notices are stored beside them. Fraunces + DM Sans is the approved pairing; Newsreader + Manrope is retained only for the documented alternative.
