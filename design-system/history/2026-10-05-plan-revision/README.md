# WeGroween design system

Version 1.2.0-proposed extends the approved **Cultivated Editorial** direction and **I1 Field Notes** iconography with the V1 voice and M1 component character. The package is a design-system reference only; it does not contain a storefront, checkout, database, payment integration or admin application.

## Selected system

- C2 Soil & Saffron
- T2 Fraunces + DM Sans
- G3 Curated Market
- V1 Cultivated Authority
- M1 Restrained Editorial

## Start here

1. Open `artifact/index.html` for the interactive system specimen.
2. Use `artifact/comparison.html` to compare the approved selection with the documented alternatives.
3. Open `artifact/iconography.html` to inspect the approved icon library; `artifact/iconography-options.html` preserves the three-direction decision archive.
4. Open `artifact/components.html` for the reviewed component and state reference.
5. Read `BRAND_IDENTITY_BLUEPRINT.md` for brand behavior and `DESIGN_SYSTEM.md` for component contracts.
6. Review the two client-facing PDFs in `pdf/`.
7. Consume `design-tokens.json` as the machine-readable source of truth or `tokens.css` for CSS custom properties.

For the most reliable local preview, serve the repository root over HTTP rather than opening the HTML using a `file:` URL. For example: `python -m http.server 4173`.

## Package map

- `BRAND_IDENTITY_BLUEPRINT.md` — identity, voice, typography, grid, imagery and governance.
- `DESIGN_SYSTEM.md` — foundations, component contracts, states, accessibility and future implementation guidance.
- `design-tokens.json` — canonical values.
- `tokens.css` — CSS custom-property adapter.
- `artifact/` — interactive system, comparison, iconography and component specimens.
- `components/` — reviewed framework-neutral component CSS and implementation guidance.
- `ICONOGRAPHY_OPTIONS.md` — icon construction comparison and the recorded I1 decision.
- `icons/` — approved I1 Field Notes sprite, 28 standalone SVGs, manifest, generator and usage guidance.
- `assets/` — specimen imagery provenance, self-hosted open-license fonts and license notices.
- `QUALITY_REVIEW.md` — Phase 6 findings, corrections, validation and disclosed limitations.
- `pdf/` — H1 homepage prototype, authoritative Design Direction Manual, maintainable print sources and QA notes.
- `DELIVERY_VALIDATION.json` — structural delivery-package validation result.
- `archive/` — project-private proposed delivery snapshots and archive log. B2 permits only a separate reviewed-redacted structural summary for shared reuse.
- `research-summary.md` — evidence synthesis.
- `decisions.md` — leader decisions and scope history.
